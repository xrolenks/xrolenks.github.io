# Fatal Fists (`fatalfists/`)

One-on-one arcade fighter (no build, no image or sound files: art drawn on a `<canvas>`, sounds made with Web Audio).

**Files (split 2026-11-20, Rick's request; was one `index.html`).** `index.html` = page HTML (canvas, touch buttons, menu screens), `css/style.css` = all styles, `js/` loaded in this order (`'use strict'` each, shared global scope): `data.js` (basics `$`/`rnd`/`ease`, `FIGHTERS`, `MOVES`, poses `P`, settings), `sound.js` (`SFX_RAW`, `SFX` wrappers), `input.js` (`keys`, `KEYMAP`, `humanInput`), `fight.js` (`G`, `NET`, fighter states, `control`, hits, blasts, `separate`), `ai.js` (computer fighter), `update.js` (`step()` + particles), `draw.js` (arena, fighters, blasts, HUD, `render`), `online.js` (PeerJS), `practice.js` (practice mode: dummy, `lowerHp`, hits/damage + frame data HUD), `menus.js` (screens, fighter select, buttons, keyboard, touch), `main.js` (`resize` + frame loop). Code that runs while a file loads may only use earlier files. First built 2026-11-20 from Rick's request: "inspired off basic Mortal Kombat mechanics, WASD to move, buttons to kick and punch". Follows the site's originality rule: the mechanics are classic fighting-game ones, but the name, fighters, arena, art and wording are ours. Don't use the other game's terms or characters (no "Fatality", "Finish him", "Flawless Victory", ninjas in its colours, etc.); we say "K.O.", "PERFECT!", "<NAME> WINS".

**Modes:** 1 Player vs the computer (Easy / Normal / Hard), **Practice**, or **Play online** (`G.mode = 'online'`, see below). Best of 3 rounds, 60 s each; time out → more health wins the round (equal = draw, nobody scores). **2 Players on one keyboard is hidden for now** (Rick 2026-11-21: its title button is commented out in `index.html`; `G.mode = '2p'` still works if it comes back).
**Practice (Rick 2026-11-21, `js/practice.js`, `G.mode = 'practice'`):** pick your fighter, then the dummy (same 2-step select as 2P; badge "YOU"). The dummy (right side) gets `dummyInput()` instead of the computer, from `PRAC.stance` ('stand' / 'crouch') and `PRAC.block` (true / false), set by **on-screen buttons in the top right** (`#dummyPanel` in `index.html`, under the dummy's health bar; shown by CSS only when `body.playing.practice`, the `practice` class is set in `show()`; buttons `data-stance` / `data-block`, `updateDummyPanel`, blur after click so game keys aren't caught). Rick moved them there from the pause menu (2026-11-21). Unlimited health: all damage goes through `lowerHp()`, which never takes the dummy below 1 (no K.O.), and `practiceTick` refills it after `DUMMY_REFILL` 50 frames left alone; no clock (timer shows ∞), no round dots, no normal combo text. HUD (`drawPracticeHUD`): **top left** = hits + total damage of the current / last combo (or "BLOCKED / chip"); **bottom right** = frame data of your last move: name, startup / active / recovery from `MOVES`, the frame it touched, and the **measured** advantage (`practiceTick`: first frame each side is free after the hit/block; + = you act first), or Knockdown / Throw / Missed. Hooks: `startMove` → `practiceMove`, `applyHit` / `releaseThrow` → `practiceContact`. Tested: Alley Spin 3 hits / 22, dummy down to 1 hp never K.O.'d and refills, jab −2 on block / +6 on hit / missed from afar, Hook +1.
