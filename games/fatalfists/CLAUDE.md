# Fatal Fists (`fatalfists/`)

One-on-one arcade fighter (no build, no image or sound files: art drawn on a `<canvas>`, sounds made with Web Audio).

**Files (split 2026-11-20, Rick's request; was one `index.html`).** `index.html` = page HTML (canvas, touch buttons, menu screens), `css/style.css` = all styles, `js/` loaded in this order (`'use strict'` each, shared global scope): `data.js` (basics `$`/`rnd`/`ease`, `FIGHTERS`, `MOVES`, poses `P`, settings), `sound.js` (`SFX_RAW`, `SFX` wrappers), `input.js` (`keys`, `KEYMAP`, `humanInput`), `fight.js` (`G`, `NET`, fighter states, `control`, hits, blasts, `separate`), `ai.js` (computer fighter), `update.js` (`step()` + particles), `draw.js` (arena, fighters, blasts, HUD, `render`), `online.js` (PeerJS), `practice.js` (practice mode: dummy, `lowerHp`, hits/damage + frame data HUD), `combos.js` (practice combo list + demonstrations), `tutorial.js` (How to play tutorial), `menus.js` (screens, fighter select, buttons, keyboard, touch), `main.js` (`resize` + frame loop). Code that runs while a file loads may only use earlier files. First built 2026-11-20 from Rick's request: "inspired off basic Mortal Kombat mechanics, WASD to move, buttons to kick and punch". Follows the site's originality rule: the mechanics are classic fighting-game ones, but the name, fighters, arena, art and wording are ours. Don't use the other game's terms or characters (no "Fatality", "Finish him", "Flawless Victory", ninjas in its colours, etc.); we say "K.O.", "PERFECT!", "<NAME> WINS".
